# Auth typography

Self-hosted Google Fonts assets: DM Sans (variable, 400–700, Latin and Latin Extended) and Instrument Serif (italic, Latin). Each font's SIL Open Font License is included beside the assets. No font request is sent to Google at runtime.

Sources: https://github.com/google/fonts/tree/main/ofl/dmsans and https://github.com/google/fonts/tree/main/ofl/instrumentserif.
